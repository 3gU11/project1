# 流水号跨批次重排方案备案

## 目的

处理前序待产批次撤销审核后，后续批次流水号连续性和机台对应关系的问题。

例如 09-05、09-06、09-07 已生成流水号，撤销 09-05 后，不能只删除 09-05 的记录而让后续批次继续沿用旧号段，造成空号或顺序错位。

## 当前已完成

- 同一批次首次生成流水号时，按启用机型字典的 `sort_order` 排序。
- 同一机型内保留原有槽位顺序。
- 已有有效流水号在重试同步时保持原机台绑定。
- 预测列中的卡片显示顺序不再直接决定不同机型的流水号先后。

## 后续改造方案

后续可增加独立的流水号分配记录，记录流水号、批次、机台、机型、分配状态、锁定时间和释放时间。

流水号建议分为：

- `ALLOCATED`：已分配但尚未产生外部业务影响，可以重排。
- `LOCKED`：已入库、打印、发货或被其他业务引用，不允许自动改号。
- `RELEASED`：批次撤销后释放，可按规则回收。

撤销前序批次时，系统应锁定受影响批次，检查后续流水号是否已锁定；只对未锁定号段重排，同时同步 `units`、`plan_import` 和正式成品数据，并写入审计日志。若发现已锁定流水号，应阻止自动重排并列出受影响批次和机台。

## 本次范围

本文档仅作方案备案。本次不实现跨批次重排、流水号锁定、释放回收和历史数据迁移。
