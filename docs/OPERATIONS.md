# 业务操作手册

## 登录与权限

使用管理员或业务角色登录。菜单和写操作由权限控制；生产环境禁止多人共用管理员账号。

## 经销商订单

1. 在“经销商订单”执行同步，确认订单号、客户、区域经理、交期和云端附加备注。
2. 区域经理初审通过后进入总部待审核；拒绝必须填写原因。
3. 总部审核通过后预览可用库存，确认备注和明细，再执行“转合同”。
4. 合同或沙盘确认后执行配货；配货后云端附加备注不再覆盖生产备注。
5. 云端同步失败时查看同步状态和重试次数，不要重复创建订单。

## 生产排产

- 录入或导入合同后，检查批次、机型、容量、交期和合同备注。
- 沙盘可使用预测重算生成虚拟批次，并切换“以销定产”和“均衡库存”策略。
- 急单插入前先确认影响范围；系统会执行链式顺延并同步看板。
- 机台交换、批量锁定和释放属于高风险操作，操作前记录原批次和备注。

## 库存、入库与发货

1. 入库时核对流水号、机型、批次和库位；历史事件写入 `inbound_history`。
2. 配货时检查库存状态（包括“已绑定”）和订单数量，系统会事务锁定。
3. 发货复核扫码或输入流水号，确认客户、订单和数量后提交。
4. 退货或撤回发货必须保留原因，并核对库存状态是否恢复。

## 报表

报表中心支持入库、订单、出货、完工、排产台账和生产跟踪单。先选择日期、批次或状态过滤，再导出 Excel。报表是查询时生成的快照；如与当前库存不同，先确认统计口径和时间范围。

## 机台档案

在机台档案中按流水号上传合同、照片或检测文件。文件名不得包含路径穿越字符；删除前确认已完成备份。
