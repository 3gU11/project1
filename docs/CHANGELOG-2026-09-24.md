## 功能与修复

| 模块 | 更新行为 |
| --- | --- |
| 预占状态 | 根据实际机台、批次、产线及库存状态，显示“待投产（已预占）”“待配货确认”或“预占异常，待核查”；保留数据库 `pending_review` 状态以兼容原流程。 |
| 等待提示 | 展示当前批次预占天数、合同交期，以及逾期或预计入库晚于交期的风险。刷新时读取当前状态；不会超时自动释放。 |
| 改配批次 | 从能够满足整份合同需求的其他已确认或在产批次中选择，释放旧机台并绑定新机台，保留原订单号；目前按整份合同改配，不提供逐台任意挑选。 |
| 撤销规划 | 对未确认配货的预占订单，释放机台关联、取消订单、恢复合同为待规划，并恢复普通排产需求或原急单队列。保留订单和变更记录。 |
| 事务保护 | 改配和撤销与确认配货共用订单锁；目标不足、关联变化、机台锁定或进入发货流程时拒绝操作，失败整体回滚。 |
| 确认配货 | 未投产且未形成可用库存时禁止确认；允许已投产或库存满足条件的原预占机台确认。按机台身份核查，兼容投产时批次拆分。 |
| 状态纠正 | 订单列表的自动状态核对不再把待确认预占订单直接改为待发货，也不恢复已取消订单。 |
| 合同管理 | 将“自动配货”提交文案改为“建单并预占”，明确可在订单配货中改配或撤销。 |
| 动态路由 | 为权限路由注册前的首次导航增加匹配入口，消除 `/order-allocation` 无匹配警告；重新导航显式保留 query/hash，避免丢失 `order_id`。无权限访问仍进入 403。 |
