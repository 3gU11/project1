# 功能演示数据库

双击项目根目录的 `run_demo.bat`，打开 http://127.0.0.1:3100 。

局域网演示请使用 `run_demo_lan.bat`，其他电脑访问 `http://本机局域网IP:3100`。
此模式只将网页端口 3100 监听到所有网卡，后端 3101/8100 仍仅监听本机。
Windows 防火墙需允许本地子网访问 TCP 3100。两种启动方式不能同时运行。

- 账号：`demo_admin`
- 密码：`Demo123456`
- 数据库：`v8_demo_showcase`
- Python / Go 端口 8100 / 3101 仅监听本机；局域网模式下网页端口 3100 监听局域网网卡。
- 页面顶部黄色提示表示当前处于演示环境。
- 启动窗口按 Ctrl+C 停止演示服务；不会停止原有业务服务。

首次启动会在数据库不存在时自动创建。再次启动保留演示过程中所做的修改，不清空任何已有数据库。

## 数据范围

仅从原数据库复制表结构和 `model_dictionary` 字典行；不复制客户、代理商、用户密码、订单、合同、流水号、日志、文件和云端配置。

以创建时启用的每个机型生成 8 台测试机：2 台空闲库存、1 台待发货、1 台已出库、2 台生产中、2 台待排产，另加 2 个预测占位。每个机型还生成 4 笔销售订单及合同、1 笔经销商待审核订单、1 个拍照任务、1 个测试配件绑定和 1 个预测批次槽位。前 5 个机型另有加急需求。出入库历史、生产履历及操作日志与测试机对应。

全部业务名称带“测试”或 `DEMO-` 标识。机型字典为创建时快照，后续原库字典修改不会自动同步。业务表为空的情况表示尚未发生相应演示操作，例如上传图片、审批历史。

提供 `demo_admin`、`demo_boss`、`demo_sales`、`demo_prod`、`demo_inbound`、`demo_aftersales`、`demo_lineoperator` 测试账号，密码相同。演示管理员具有全部页面权限；其他角色沿用代码内置权限。

## 隔离与使用边界

原 `.env`、业务库和原有服务端口不切换。演示的 Python 与 Go 连接同一独立库。演示关闭云端推送、云端拉单、维修同步和 Redis，云端 HTTP 地址指向不可用的本机端口；真实 OCR 服务不接入。测试文件存放于 `output/<演示库名>/`，服务日志也在此目录。

用于功能展示及测试操作，不用于真实发货、云端集成或真实 OCR 验收。当前只启动桌面网页演示入口，没有启动手机端独立服务。

## 创建另一套新数据

在项目目录运行（库名必须以 `v8_demo_` 开头）：

```powershell
.\.venv\Scripts\python.exe scripts\demo_database.py --database v8_demo_second
.\.venv\Scripts\python.exe scripts\run_demo.py --database v8_demo_second
```

生成脚本遇到已有数据库会拒绝覆盖。切换另一演示库前，应先停止当前演示窗口，释放 3100、3101、8100 端口。
