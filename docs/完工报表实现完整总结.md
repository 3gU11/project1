### 3. 数据逻辑

#### 统计规则

**"产出" = "入库"**

```sql
SELECT COUNT(*) FROM inbound_history
WHERE inbound_time BETWEEN :start_date AND :end_date
  AND COALESCE(status_after, '') <> '待入库'
  AND COALESCE(status_after, '') <> ''
```

**包含的入库方式**：
- ✅ 手动入库（`source = '机台入库'`）
- ✅ 直接配货-自动入库（`source = '直接配货-自动入库'`）
- ✅ 配货自动入库（`source = '配货自动入库'`）

**统计逻辑**：
- 每条 `inbound_history` 记录 = 1台机器
- `COUNT(*)` = 产出的机器数量
- 不会重复统计（唯一索引保证）

### 4. 历史数据处理

#### 回填功能

**数据来源**：`transaction_log` 表

**回填方法**：

1. **命令行脚本**：
   ```bash
   python scripts/backfill_inbound_history.py
   ```

2. **API接口**：
   ```http
   POST /api/reports/backfill-inbound-history
   ```

**回填逻辑**：
- 从 `transaction_log` 提取入库操作记录
- 从 `finished_goods_data` 或 `shipping_history` 补充详细信息
- 使用 `INSERT IGNORE` 避免重复

## 🔍 数据验证

### 验证方法

**在数据库中验证**：

```sql
-- 查询总产出
SELECT COUNT(*) as total
FROM inbound_history
WHERE inbound_time BETWEEN '2026-05-01' AND '2026-05-31'
  AND COALESCE(status_after, '') <> '待入库'
  AND COALESCE(status_after, '') <> ''

-- 按入库方式分类
SELECT source, COUNT(*) as count
FROM inbound_history
WHERE inbound_time BETWEEN '2026-05-01' AND '2026-05-31'
  AND COALESCE(status_after, '') <> '待入库'
  AND COALESCE(status_after, '') <> ''
GROUP BY source

-- 按日期统计
SELECT 
    DATE_FORMAT(inbound_time, '%Y-%m-%d') as date, 
    COUNT(*) as count
FROM inbound_history
WHERE inbound_time BETWEEN '2026-05-01' AND '2026-05-31'
  AND COALESCE(status_after, '') <> '待入库'
  AND COALESCE(status_after, '') <> ''
GROUP BY DATE_FORMAT(inbound_time, '%Y-%m-%d')
ORDER BY date
```

## ⚠️ 注意事项

### 1. 历史数据

- 首次使用前建议执行回填
- 回填取决于 `transaction_log` 的数据范围
- 可以重复执行回填（不会产生重复数据）

### 2. 数据完整性

- 自动入库没有库位信息（正常）
- 部分历史数据可能缺少操作员信息
- 入库时间 = 机器进入库存系统的时间

### 3. 性能

- 大数据量查询可能需要几秒
- 建议按月查询，避免一次查询太长时间范围
