## 📊 完工报表功能

### 统计内容

**"产出" = "入库"**

统计所选时间段内产出的机台数量，包括：
- ✅ 手动入库的机台
- ✅ 配货自动入库的机台
- ✅ 沙盘生产的机台
- ✅ 直接导入的机台

### 筛选条件

- **查询方式**：日期范围 / 按月份
- **机型**：可选筛选
- **客户**：可选筛选

### 报表内容

**汇总表**：
- 按日期、批次号、机型分组
- 显示产出数量
- 包含客户、代理商信息

**明细表**：
- 每台机器的详细入库记录
- 包含流水号、入库时间、操作员等

## 🔧 技术实现

### 后端API

**端点**：`GET /api/reports/completions`

**逻辑**：复用入库报表逻辑

```python
@router.get("/completions")
def generate_completion_report(...):
    """完工报表（产出统计）"""
    # 复用入库报表数据
    summary_df, detail_df = get_inbound_report_data(
        start_date, end_date, model_type, customer
    )
    return _generate_excel_response(sheets, f"完工报表_{start_date}_{end_date}")
```

### 数据来源

**表**：`inbound_history`

**查询**：
```sql
SELECT * FROM inbound_history
WHERE inbound_time BETWEEN :start_date AND :end_date
  AND status_after <> '待入库'
  AND status_after <> ''
```
