## 2. 启动 / 停止

```powershell
cd D:\CURSORpj\V8BetaV1.1

# API 8000（detached，日志写到售后仓库 runtime-logs/local-test/v8-api.*）
Start-Process -FilePath "$PWD\.venv\Scripts\python.exe" `
  -ArgumentList '-m','uvicorn','api.main:app','--host','127.0.0.1','--port','8000' `
  -WorkingDirectory $PWD -WindowStyle Hidden `
  -RedirectStandardOutput 'D:\CURSORpj\售后\runtime-logs\local-test\v8-api.log' `

  -ArgumentList 'frontend\node_modules\vite\bin\vite.js','--host','127.0.0.1','--port','3000','--strictPort' `

  -RedirectStandardOutput 'D:\CURSORpj\售后\runtime-logs\local-test\v8-frontend.log' `
  -RedirectStandardError  'D:\CURSORpj\售后\runtime-logs\local-test\v8-frontend.err.log' `
  -PassThru | % { $_.Id } | Set-Content 'D:\CURSORpj\售后\runtime-logs\local-test\v8-frontend.pid'
```

## 3. 依赖的本机服务（属于售后仓库）

| 服务 | 地址 | 说明 |
|---|---|---|
| 本地网关 | `http://127.0.0.1:8090` | V8 的唯一出口 |
| 桥接 | `http://127.0.0.1:8003` | 订货小程序 server 的只读副本，读 `aftercare_local.dealer_orders_v8` |
| Spring | `http://127.0.0.1:8788` | 合同附件、`v8-status` 回写、机台快照 |

网关分流：`/api/v8/bridge/*` → 桥接；`POST /api/dealer/orders/{no}/v8-status` → Spring（注入静态鉴权头）；
其他 `/api/dealer/*` → 桥接；`/api/v7/*`、`/api/v8-sync/*` 及其他 → Spring。
