# 项目总览

## 系统定位

系统面向离散制造场景，覆盖经销商订单、合同与排产、成品库存、入库、配货、发货、机台档案和 Excel 报表。主系统由 FastAPI 业务中台、Go 调度服务、Vue PC 管理端和 Vue/Vant 移动端组成。

## 核心业务闭环

```text
经销商订单 -> 区域经理初审 -> 总部审核 -> 转 V7 合同
    -> 沙盘预测/急单插入/机台排产 -> 配货锁定 -> 入库
    -> 发货复核 -> 完工与云端状态同步 -> 审计与报表
```

关键状态包括 `regional_pending`、`pending`、`approved`、`rejected`、`contracted`、`allocated`、`completed`。具体状态转换以接口校验和数据库现状为准，人工修改数据库前必须先备份。

## 功能模块

- **经销商订单**：云端订单同步、两级审核、备注隔离、转合同、配货和状态回写。
- **生产计划**：合同录入、批次和机台安排、急单链式插入、容量匹配顺延、沙盘预测。
- **库存管理**：库存查询、已绑定状态、库位布局、入库、配货、发货和退货。
- **机台档案**：按流水号归档合同文件、照片和缩略图，支持预览、下载和批量删除。
- **报表中心**：入库、订单、出货、完工和排产台账导出，支持 Excel 多 Sheet。
- **审计与权限**：用户、角色、权限、操作日志和全链路追踪。
- **移动端**：面向 PDA/手机的扫码查询、库位调拨和发货复核。

## 不在本仓库范围内

微信小程序云端业务、云端 MySQL 和维修系统服务不随本项目启动；它们通过环境变量配置的 HTTP 接口对接。云端密钥、生产数据库备份、合同原件和运行日志不应提交到公开仓库。
