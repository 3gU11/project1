# 安全基线

## 密钥与配置

- 生产环境必须修改 `ADMIN_PASSWORD`、`GO_INTERNAL_TOKEN` 和 JWT 签名密钥，不要使用代码默认值。
- `.env`、云端 API key、数据库密码、HMAC secret、mTLS 私钥和生产备份不得提交 Git。
- 令牌通过环境变量或密钥管理服务注入，日志中不得打印完整 token、密码或客户敏感信息。

## 访问控制

- MySQL 仅开放给应用服务器内网，应用使用最小权限账号。
- 管理端和 API 通过 HTTPS 暴露；开发服务器不得直接公网监听。
- `X-Internal-Token` 仅用于服务间调用，禁止放入浏览器代码或前端构建变量。
- 生产账号使用个人身份和最小角色，重要操作保留审计记录。

## 数据与文件

- 合同、客户、手机号、机台照片和维修快照属于业务敏感数据，应限制目录权限并加密备份。
- 上传接口必须限制文件类型、大小和路径；下载接口必须经过登录和资源授权。
- 数据修复前备份，修复后验证，定期进行恢复演练。

## 泄露响应

若发现密钥已提交或泄露：立即吊销并重发密钥、轮换数据库密码、检查访问日志，再通过 Git 历史清理敏感内容并通知受影响人员。仅删除当前文件不能消除历史提交中的密钥。
