## 📊 完工报表逻辑

### 数据来源

**表**：`inbound_history`（入库历史）

### 统计规则

**"产出" = "入库"**

- 包含所有入库方式：手动入库、配货自动入库
- 入库时间 = 机器进入库存系统的时间
- 数据完整、准确、可追溯

### 查询逻辑

```sql
SELECT * FROM inbound_history
WHERE inbound_time BETWEEN :start_date AND :end_date
  AND COALESCE(status_after, '') <> '待入库'
  AND COALESCE(status_after, '') <> ''
  AND (:model_type = '' OR model = :model_type)
  AND (:customer = '' OR customer = :customer)
```

### 汇总维度

- 按日期、批次号、机型、客户、代理商分组
- 统计产出数量

## 📋 与其他报表的关系

### 报表体系

```
1. 【完工报表】（新实现）
   - 数据来源：inbound_history
   - 用途：产量统计、财务对账
   - 特点：数据完整、时间准确

2. 【入库报表】（已有）
   - 数据来源：inbound_history
   - 用途：入库追踪、操作审计
   - 特点：详细的入库操作记录

3. 【生产台账报表】（可选，保留旧逻辑）
   - 数据来源：production_history_ledger
   - 用途：生产效率分析、产线绩效
   - 特点：包含产线、生产时长信息
```

### 区别说明

**完工报表 vs 入库报表**：
- 数据来源相同（`inbound_history`）
- 查询逻辑相同
- 展示维度不同：
  - 完工报表：强调"产出数量"，按日期汇总
  - 入库报表：强调"入库操作"，显示详细记录
