# 完工报表简化方案

## 🎯 需求

**只需要知道：造完了多少台机器**

---

## 📊 最简单的统计逻辑

### 查询SQL

```sql
SELECT 
    DATE_FORMAT(ih.inbound_time, '%Y-%m-%d') AS `日期`,
    COUNT(*) AS `产出数量`
FROM inbound_history ih
WHERE ih.inbound_time BETWEEN :start_date AND :end_date
  AND COALESCE(ih.status_after, '') <> '待入库'
  AND COALESCE(ih.status_after, '') <> ''
GROUP BY DATE_FORMAT(ih.inbound_time, '%Y-%m-%d')
ORDER BY DATE_FORMAT(ih.inbound_time, '%Y-%m-%d') DESC
```

### 结果示例

| 日期 | 产出数量 |
|------|---------|
| 2026-05-30 | 50 |
| 2026-05-29 | 45 |
| 2026-05-28 | 38 |
| **总计** | **133** |

## ✅ 最简单的答案

**造完了多少台机器 = `inbound_history` 表中的记录数**

```sql
SELECT COUNT(*) FROM inbound_history
WHERE inbound_time BETWEEN '2026-05-01' AND '2026-05-31'
  AND status_after <> '待入库'
  AND status_after <> ''
```
