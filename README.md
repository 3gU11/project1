# V7STD1.0 智能生产排产与成品库存管理系统

> **"让每一台机台都有迹可循，让每一次排产都智慧感知"** —— 专为离散制造业打造的生产指挥与实物库存全链路闭环平台。

## 🌟 核心亮点

V7STD1.0 突破了传统 ERP 与生产现场的“最后一公里”断层，通过 **"FastAPI 业务脑" + "Go 调度引擎"** 的双心架构，实现了从预测排产到终端发货的数字化闭环。

### 1. 🧠 智能生产调度引擎 (Go Core)
*   **🚀 链式急单插单 (Rush Chain Shifting)**: 系统独创的链式位移算法。当急单插入时，系统会自动识别受影响的生产序列，实现生产线与沙盘看板的整体平滑后移，确保交付优先级。
*   **📊 预测性排产 (Sandbox)**: 基于机型目标比例 (Capacity Ratio) 自动生成的虚拟批次，通过智能预测算法填充未来产能，支持“以销定产”与“均衡库存”双模式切换。
*   **🔄 灵活插槽置换 (Slot Swapping)**: 支持生产过程中任意两个工位/机台订单内容的秒级置换，自动同步相关联的合同与交期。

### 2. 👁️ 数字化看板与交互增强 (Desktop)
*   **🎯 动态队列筛选**: 生产看板待排产区新增**机型大类下拉过滤器**，支持中小型G、中大型XS、AUTO等分类即时筛选。
*   **📈 悬浮统计大盘**: 集成可收缩的统计面板，实时计算在产/待排的订单分布，并支持**“一键定位”**功能，快速聚焦特定产线位置。
*   **🔒 批量锁定交互**: 支持在监控视图批量勾选机台卡片，统一覆盖备注并执行事务锁定，极大提升批量调整效率。

### 3. 📱 移动助手与现场作业 (Mobile Terminal)
*   **⚡ 渐进式渲染 (Progressive Rendering)**: 专为低性能手机/PDA 优化。通过分批加载机制，流畅支撑上千台机台档案的即时滑动，彻底告别移动端卡顿。
*   **🏭 库管/入库双模式**:
    *   **库管模式**: 提供“🚢 待发货复核”快捷入口，一键锁定已配货待发的实物。
    *   **入库模式**: 增强型批量入库弹窗，库位矩阵实时显示**“当前/最大”容量感知**，避免库位溢出。
*   **🔍 智能检索**: 支持批次号、流水号、机型、库位多维度模糊搜索，配合扫码槍实现“所扫即所得”。

### 4. 📄 机台全生命周期档案 (Asset Traceability)
*   **🔗 “已绑定 (Bound)”状态管理**: 引入全新的逻辑状态。精准区分“名花有主”的在途机台与“公共现货”，在库存查询中提供独立统计块与筛选维度。
*   **📷 OCR 自动化入库**: 集成 **PaddleOCR**。支持 PDF 跟踪单、拍摄照片自动解析，实现流水号与合同号的秒级自动匹配。
*   **🔍 全链路审计追踪**: 精确到秒级的业务日志。记录从合同录入、排产分配、入库审核到发货完成的所有变更行为。

## 🛠️ 技术架构

| 组件 | 核心栈 | 职责描述 |
|------|--------|----------|
| **调度引擎** | **Go 1.21 + GORM** | 负责高并发排产重算、复杂急单位移算法及 WebSocket 实时状态广播。 |
| **业务中台** | **FastAPI + SQLAlchemy** | 处理业务逻辑、OCR 扫描、机台档案管理、权限校验与审计。 |
| **管理前端** | **Vue 3 + TS + Element+** | 提供 Boss 视角、销售配货、生产统筹等 PC 端深度管理界面。 |
| **手持端** | **Vue 3 + Vant UI** | 适配移动端/PDA，专注于实物扫码、库位调拨与现场确认。 |
| **数据底座** | **MySQL 8.0** | 采用原生 SQL 优化，确保配货锁定与状态变更的原子性。 |

## 📅 近期优化记录

### 2026-05-15 (双向同步闭环工程)
- **✅ 闭环补全**: 实现了主系统与沙盘看板的 4 大同步缺口（订单删除清理、合同编辑联动、配货 SN 写回、看板信息回传）。
- **🔒 安全加固**: 引入 `X-Internal-Token` 机制，确保 Go 调度引擎与 Python 业务中台通讯的零信任安全。
- **🚀 效率优化**: 引入 `fire-and-forget` 异步同步模型，核心交易不再受同步延迟影响。

### 2026-05-09 (库存稳定性与“已绑定”状态)
- **🛠️ 锁机制引入**: 核心配货逻辑改用原生 SQL 写入，彻底解决因 `pandas` 缓存导致的并发覆盖问题。
- **🔗 状态贯通**: 在 `InventoryQuery.vue` 中全面集成“已绑定”筛选与统计指标块。
- **⚡ 缓存革新**: 移除不稳定的 LRU 缓存，通过数据库级索引优化提升查询响应速度。

### 2026-05-07 (看板交互与拖拽规则)
- **🎯 交互升级**: 看板待排区新增分类下拉过滤；新增混放提示与视觉标记。
- **📦 顺延算法修复**: 顺延逻辑由“顺序后移”改为“容量匹配后移”，避免跨大小机列导致的数据错位。
