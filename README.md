# V7STD1.0 智能生产排产与成品库存管理系统

> **"让每一台机台都有迹可循，让每一次排产都智慧感知"** —— 专为离散制造业打造的生产指挥与实物库存全链路闭环平台。

---

## 🌟 核心亮点与系统功能

V7STD1.0 突破了传统 ERP 与生产现场的“最后一公里”断层，通过 **"FastAPI 业务中台 (Python)" + "智能调度引擎 (Go Core)" + "小程序云中台 (V8 Cloud)"** 的三维协同架构，实现了从前端经销商下单、工厂预测性排产到终端实物发货的数字化闭环。

### 1. 🧠 智能生产调度引擎 (Go Core Engine)
*   **🚀 链式急单插单 (Rush Chain Shifting)**: 系统独创的链式位移算法。当急单插入时，系统会自动识别受影响的生产序列，实现生产线与沙盘看板的整体平滑后移，确保交付优先级。
*   **📊 预测性排产 (Sandbox)**: 基于机型目标比例 (Capacity Ratio) 自动生成的虚拟批次，通过智能预测算法填充未来产能，支持“以销定产”与“均衡库存”双模式切换。
*   **🔄 灵活插槽置换 (Slot Swapping)**: 支持生产过程中任意两个工位/机台订单内容的秒级置换，自动同步相关联的合同与交期。
*   **📐 智能顺延保护 (Family Capacity Matching)**: 顺延逻辑由“顺序后移”改为“容量匹配后移”。大机/小机容量不同的批次，顺延时会自动寻找后续相同容量的批次，避免跨大小机列导致的数据与排产错位。

### 2. 🌐 经销商协同与小程序云集成 (WeChat Cloud/V8 Integration)
*   **🔄 二级审核工作流 (Two-Stage Review)**: 支持微信小程序端经销商订单的两级审批。订单状态流转为：区域经理初审 (`regional_pending` -> `pending`/`regional_rejected`) ➡️ 总部核准 (`pending` -> `approved`/`rejected`)。
*   **✉️ 事务性发件箱模式 (Outbox Pattern)**: 新增 `cloud_sync_outbox` 机制，保证本地对经销商订单状态的操作（如审核通过、转合同、已配货、已完工）能可靠地与云端同步，具备网络错误退避重试（30s、2m、5m、10m阶梯式重试）和幂等保证。
*   **⚡ 双重数据库监控器 (Database Observers)**:
    *   `watch_dealer_orders_db`: 每秒监测经销商订单表的变动，实时汇总待审核数量，并通过全局 WebSocket 连接广播给 PC 管理端。
    *   `watch_finished_goods_db`: 每两秒自动捕获成品库存数据的更新（入库/配货/发货等），即时触发云端库存快照同步 (`wechat_batch_summary`)。
*   **📝 云端附加备注隔离 (`cloud_extra_remark`)**: 支持接收经销商在云端改单时追加的备注，不再用云端备注强行覆盖 V7 原有备注，并将其冻结在配货前（未配货前可参与转合同与排产；配货后锁定，防止污染已生产机台的真实备注）。
*   **🛒 订单配货与合同转换**: 支持一键将核准后的经销商订单转为 V7 规划合同。合同与配货（支持撤回与 SQL 锁防并发覆盖）全链路贯通。

### 3. 👁️ 数字化看板与交互增强 (PC Desktop)
*   **🎯 动态队列筛选**: 生产看板待排产区新增**机型大类下拉过滤器**，支持中小型 G、中大型 XS、AUTO 等分类即时筛选。
*   **📈 悬浮统计大盘**: 集成可收缩的统计面板，实时计算在产/待排的订单分布，并支持**“一键定位”**功能，快速聚焦特定产线位置。
*   **🔒 批量锁定交互**: 支持在监控视图批量勾选机台卡片，统一覆盖备注并执行事务锁定，极大提升批量调整效率。

### 4. 📊 智能报表中心 (Automated Reporting)
*   **📋 排产台账导出**: 自动生成各批次在 300, 400, 500, 600, 7055, 8055, 8060 等主打机型列上的具体排产机型、备注与合计，智能匹配预计入库时间。
*   **🎫 跟踪单明细导出**: 一键将已确认/生产中以及待排产的机台，按批次导出具体的型号（含特殊非标配置备注）以及对应的生产编号（流水号/机台 ID）。
*   **🎨 专业报表样式**: 支持单 Sheet、多 Sheet 按需导出。自动应用优雅绿/暖橙主题、自适应列宽、居中对齐及边框，开箱即用。

### 5. 📄 机台全生命周期档案 (Asset Traceability)
*   **🔗 “已绑定 (Bound)”状态管理**: 引入全新的逻辑状态。精准区分“名花有主”的在途机台与“公共现货”，在库存查询中提供独立统计块与筛选维度。
*   **📷 精简运行依赖**: 移除未使用的 Python OCR 库及文本解析依赖（PaddleOCR、pdfplumber、docx），极致精简系统运行环境，提升系统稳定性。
*   **🔍 全链路审计追踪**: 精确到秒级的业务日志。记录从合同录入、排产分配、入库审核到发货完成的所有变更行为。

## 🛠️ 技术架构

| 组件 | 核心技术栈 | 职责描述 |
|------|--------|----------|
| **调度引擎** | **Go 1.21 + GORM** | 负责高并发排产重算、复杂急单位移算法及 WebSocket 实时状态广播。 |
| **业务中台** | **FastAPI + SQLAlchemy + HTTPX** | 处理业务逻辑、机台档案管理、权限校验与审计；内置双 DB Watcher 线程、云端同步 Outbox 守护任务。 |
| **管理前端** | **Vue 3 + TS + Element Plus** | 提供决策视图、销售配货、生产统筹、经销商订单两级审核、报表中心等 PC 管理端深度控制界面。 |
| **手持终端** | **Vue 3 + Vant UI** | 适配移动端/PDA，专注于实物扫码、库位调拨与发货复核。 |
| **数据底座** | **MySQL 8.0** | 采用原生 SQL 优化与多级事务索引，确保配货锁定与状态变更的强一致性与原子性。 |
