# V7STD1.0 成品库存管理系统

> 面向制造业的机台库存全生命周期管理平台

## 项目概述

V7STD1.0 是一个专为制造企业设计的成品库存管理系统，围绕 **"合同 → 排产 → 入库 → 订单配货 → 发货 → 档案"** 形成业务闭环。系统支持多角色协作、生产沙盘规划、机型比例预测、库位可视化、交易全链路追溯等核心功能。

系统采用 **FastAPI (Python)** 与 **Go** 双后端架构：
- **FastAPI**: 处理核心业务逻辑、权限管理、库存管理及报表统计。
- **Go**: 负责高性能沙盘预测排产 (Sandbox)、全量数据重算及 WebSocket 实时同步。

## 技术架构

## 核心功能模块

### 1. 生产统筹与沙盘 (Boss/Sales)
- **🧩 生产沙盘**: 预测排产批次管理、拖拽调序、急单插入、批次审核。
- **📊 比例配置**: **机型目标比例配置 (Capacity Ratio Editor)**，可视化库存分布并自动指导排产达成目标结构。
- **🚀 自动重算**: 合同录入成功后后台自动触发全量重算，沙盘卡片即时更新。

### 2. 库存与入库 (Prod/Inbound)
- **📥 成品入库**: 跟踪单 OCR 解析导入，自动识别并指派「已绑定」状态。
- **🔗 已绑定状态**: 特指已在排产计划中指派合同、但尚未入库的机台，入库审核时自动隔离。
- **🗺️ 库位大屏**: 2D 可视化库位图，支持点击查看机台详情。

### 3. 销售与发货 (Sales/Prod)
- **📦 订单配货**: 从库存锁定机台（直接 SQL 写入，杜绝缓存覆盖 Bug），支持配货撤回。
- **🚛 发货复核**: 扫描/勾选确认发货，自动更新库存状态并归档。
- **🔧 机台档案**: 机台全生命周期文件上传、预览、下载及历史追溯。

### 4. 系统管理 (Admin)
- **🔍 综合查询**: 支持「已绑定」独立计数、**加高机型统计**、长效期预警等。
- **📊 审计日志**: 记录所有关键业务操作（配货、修改状态、删除订单等）。
- **📖 机型字典**: 族系归类管理（G/XS/AUTO/SPECIAL），支持族系代码标准化自动转换。

| 角色 | 权限范围 | 特色权限 |

## 快速启动

### 1. 克隆与配置
```bash
cd V7STD
cp .env.backend.example .env
# 编辑 .env 配置数据库连接信息
```

### 2. 启动服务 (推荐方式)
使用根目录的启动工具进行一键部署：
```bash
run_fullstack.bat
```
或直接运行：
```bash
launcher.exe
```

### 3. 开发模式启动
- **后端**: `python run_api.py` (端口 8000)
- **沙盘**: `cd server && go run main.go` (端口 3001)
- **前端**: `cd frontend && npm run dev` (端口 3000)

## 业务状态流转

### 机台状态
```
待入库 / 已绑定 → 库存中(库位) → 待发货 → 已出库
            ↑___________________________↓
                    (发货撤回可回退)
```
- **已绑定**: 已指派合同但未入库。
- **待发货**: 已配货给销售订单。

### 合同状态
`待规划` → `已规划` → `已下单` → `已转订单` → `已取消`
